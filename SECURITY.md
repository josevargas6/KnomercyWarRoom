# Security and Addon-Safety Policy

KWR must comply with World of Warcraft's protected-action and secret-value
restrictions.

Do not publish potentially exploitable automation, taint, account-data, or
secret-value findings in a public issue. Use GitHub's private vulnerability
reporting feature when available, or contact the repository owner privately.

Routine Lua errors, incorrect battleground logic, UI defects, and performance
regressions should use the normal issue templates.

Supported security fixes target the latest development candidate and the most
recent certified rollback release.
