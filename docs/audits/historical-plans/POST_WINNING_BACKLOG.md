# Historical: KWR Post-Winning Backlog

This file holds ideas that do not belong in the current winning-state execution
program.

Rule:
- nothing from this file enters the active alpha execution pass unless it
  replaces an existing owner/system and directly improves the current winning
  state without increasing cognitive load.

## Deferred by policy

- new map families not already supported by the active product scope
- new composition databases that do not replace the current reviewed source
- second decision-brain or advisor systems
- additional live HUD/window families
- speculative export formats that do not replace an existing flow
- unsupported secure-action claims or automation ideas
- post-alpha marketing embellishments that do not improve commander trust,
  runtime quality, or release readiness

## Notes

When deferring an item, record:

- the idea
- why it is deferred
- what current owner/system it would affect
- what hard proof would be required before it is allowed back into scope
