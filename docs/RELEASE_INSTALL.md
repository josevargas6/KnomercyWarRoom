# Install Knomercy War Room Alpha 43

Download and extract both release ZIPs directly into:

`World of Warcraft/_retail_/Interface/AddOns/`

The resulting folders must be `KnomercyWarRoom` and `KWRSentinel`; do not
nest them in an extra versioned folder. Enable both addons at character select,
then use `/kwr` in a rated battleground.

Verify the ZIPs against the accompanying `SHA256` file and
`PUBLIC_MANIFEST.json` before reporting an installation issue. Developer
sources, screenshots, field evidence, and certification reports are retained
only as time-limited CI artifacts or version-controlled evidence; they are not
player downloads.
