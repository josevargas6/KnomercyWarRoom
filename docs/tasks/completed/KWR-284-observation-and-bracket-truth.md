# Objective

Fix the remaining two original audit reproductions: re-stamped observations and
Blitz classification inferred and latched from a partial standard roster.

# User outcome

Repeated processing cannot make an old observation appear newly acquired.
Seeing eight players on each side cannot switch standard battleground mechanics
to Blitz. Rated Solo RBG and Solo RBG brawl indicators can positively identify it.

# Current behavior

FactStore replaces each row's observation time with processing time and confirms
every friendly row. Sensors accepts and latches TeamResolver's 8+8 inference,
while checking only the brawl API rather than the rated Solo RBG indicator.

# Required behavior

- Preserve a finite nonnegative row observation timestamp (observedAt,
  lastSeenAt, then capturedAt), or leave it unknown. Keep generatedAt distinct.
- No row without a timestamp becomes a confirmed fact. Do not blanket-confirm
  friendly row fields from roster presence. Preserve explicit confidence labels
  only with a known nonfuture observation time.
- Preserve captured context time in its fact; do not replace it during projection.
- Use public explicit Solo RBG indicators through TeamResolver. Treat nil,
  exceptions and protected results as unknown; record the source and known state.
- An 8+8 scoreboard is a hint only. Recompute classification from current explicit
  evidence so later contradictory public results clear it; no scoreboard latch.

# Non-goals

Per-field authority/expiry, completeness, source identity, unique match generation,
training classification and all bracket-specific mechanics remain wider OVR-02/06
work. Timestamp preservation alone does not certify freshness or tactical quality.

# Technical constraints

Keep legacy isBlitz and blitzSource fields while exposing whether the indicator
is known. No persisted schema change. Existing post-match truth freezing remains;
it must use the explicit source generated by Sensors.

API reference reviewed September 5: Blizzard-generated
[PvP documentation](https://raw.githubusercontent.com/Gethe/wow-ui-source/live/Interface/AddOns/Blizzard_APIDocumentationGenerated/PvpInfoDocumentation.lua)
in the published UI-source mirror lists IsRatedSoloRBG, IsBrawlSoloRBG and
IsSoloRBG. Physical-client behavior remains an OVR-07/21 check.
