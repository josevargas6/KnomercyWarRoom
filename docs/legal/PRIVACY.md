# KWR Sentinel Privacy Policy

Effective Date: 2026-07-05

KWR Sentinel is a Discord bot created for the Knomercy War Room community. This policy explains what information the bot may collect and how it may be used.

## Information the Bot May Collect

KWR Sentinel may collect information that users voluntarily submit through Discord commands, messages, forms, or attachments, including:

- Discord user ID and username.
- Server ID and channel ID.
- Command usage.
- AAR submissions.
- Bug reports.
- Diagnostic reports.
- Strategy submissions.
- Suggestions.
- Moderation reports.
- Uploaded screenshots or text files.
- Message content submitted directly to bot commands.

## How Information Is Used

Collected information may be used to:

- Provide bot responses.
- Help users install or troubleshoot the KWR addon.
- Review bug reports and diagnostics.
- Create GitHub issues for development review.
- Improve KWR documentation, Academy content, and addon behavior.
- Support moderation and server safety.
- Track community contributions.

## AI Processing

Some submitted text may be processed by AI services to summarize, classify, moderate, or respond to support, strategy, diagnostic, and Commander/Scout AI requests.

Users should not submit passwords, API keys, Discord tokens, Battle.net credentials, private account information, or sensitive personal information.

## GitHub Sync

If enabled, KWR Sentinel may create GitHub issues from user-submitted reports, suggestions, strategies, diagnostics, or AARs. These issues may include the information submitted by the user.

The KWR team should avoid posting unnecessary private information in public GitHub issues.

## Data Sharing

KWR Sentinel does not sell user data.

Information may be shared with KWR server staff, developers, moderators, GitHub repositories used for KWR development, and AI services used to process bot requests.

## Data Retention

Submitted information may be retained for as long as needed for support, moderation, development, testing, or historical review.

Users may request removal of their submitted information by contacting the server owner or staff team.

## Security

Bot tokens, API keys, and private credentials should never be submitted to KWR Sentinel. If a token or secret is accidentally posted, it should be reset immediately.

## Children

KWR Sentinel is intended for Discord communities and users who are old enough to use Discord under Discord's own Terms of Service.

## Changes

This policy may be updated as KWR Sentinel changes. Updated versions will be posted in the KWR GitHub repository or official Discord server.

## Contact

For questions about this Privacy Policy, contact the Knomercy War Room server owner or staff team through Discord.
